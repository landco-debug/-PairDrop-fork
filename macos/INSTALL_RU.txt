PairDrop Fork — первая тестовая сборка для Apple Silicon (macOS 14+)

1. Перетащите PairDrop Fork.app в «Программы» и откройте.
2. Сборка подписана локальной подписью, без нотариального заверения Apple.
   Если Gatekeeper блокирует запуск, используйте системные настройки
   «Конфиденциальность и безопасность» → «Всё равно открыть» для этой сборки.
3. Разрешите уведомления. Закрытие окна оставляет приёмник работающим.
   Значок в строке меню включается отдельно; открыть окно можно через Dock.
4. На Android пока используйте PairDrop. В разделе сопряжения введите на одном
   устройстве шестизначный код с другого устройства.
   В этой Mac-сборке сервер сигнализации — публичный pairdrop.net.
5. Текст: выделите → правый клик → Службы → Отправить через PairDrop.
   Файлы: Finder → правый клик → Службы → Отправить через PairDrop.
   При необходимости включите службу в настройках клавиатуры → Сочетания → Службы.
6. Меню «Поделиться → PairDrop» предоставляется встроенным Share extension.
   Включите его в системных настройках расширений «Общий доступ», если он скрыт.
   Регистрация расширения с локальной подписью требует проверки на вашем Mac.
   Службы работают как отдельный путь отправки.
7. При первой отправке выберите телефон. Сопряжённое устройство запоминается.
   Отсутствующему получателю ничего не пересылается автоматически позднее.
8. По нажатию на уведомление со ссылкой открывается браузер; с текстом —
   текст копируется в системный буфер. Файлы сохраняются в Загрузки/PairDrop;
   нажатие на их уведомление показывает сохранённый файл в Finder.

Для постоянного приёма Mac должен бодрствовать, а приложение — работать.
Cmd+Q завершает приёмник. Нулевого потребления памяти у фонового приёма нет.
Фоновая доступность штатного Android-клиента этой Mac-сборкой не исправляется.
На Android пока необходимо держать клиент активным на время обмена.

Сборка тестовая. Интернет-режим зависит от PairDrop и доступности WebRTC/TURN.
Нет установленного приложением ограничения размера. Нужны свободное место
и рабочее соединение; старый Android-клиент может расходовать память на Blob.
В Mac-клиенте файлы читаются/записываются частями, без целого файла в JSON.
Готовый общий буфер картинок или файлов эта версия не реализует.
