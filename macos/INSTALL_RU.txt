PairDrop Fork v4 — Apple Silicon, macOS Sequoia 15

Обновление
1. Активируйте старый PairDrop Fork и завершите его через Cmd+Q.
   Красная кнопка только скрывает окно и оставляет приёмник работающим.
2. Замените PairDrop Fork.app в «Программах» новой копией и откройте её.
   Название окна новой версии: «PairDrop Fork · v4». Сопряжение сохраняется.
3. Закройте старые вкладки pairdrop.net в Chrome. Вкладка Chrome «M1» и
   приложение — два независимых приёмника. Пока оба открыты, на телефоне
   закономерно видны два Mac. Приложение не может автоматически закрыть Chrome.

Новая версия работает БЕЗ значка в Dock, в том числе когда окно открыто.
Открыть окно можно повторным запуском приложения через Finder/Launchpad.
В правой части панели окна есть «Меню»: показать/закрыть окно, входящие запросы,
завершить приёмник, включить или скрыть отдельный значок в строке меню.
Никакой значок в строке меню не требуется для приёма или отправки.

Двусторонний текстовый буфер
Выделите текст на Mac → Службы → Отправить текст через PairDrop.
На Android: выделите текст → Отправить через PairDrop (иногда в меню ⋮).
Текст от сопряжённого устройства сразу попадает в буфер принимающей стороны.
Дальше используйте «Вставить» на Android или Cmd+V на Mac.
Автокопирование можно выключить в меню каждого клиента. Для несопряжённых
отправителей остаётся ручное копирование; содержимое буфера не отслеживается.
Если новая Служба ещё не видна, включите её в настройках клавиатуры → Сочетания
клавиш → Службы → Текст, затем перезапустите приложение, где выделяете текст.

Первая отправка и сопряжение
4. На A57 установите новый APK PairDrop Fork из архива и откройте его.
   Это отдельный Android-клиент: сопрягите его заново, старое приложение закройте.
   В разделе сопряжения введите шестизначный код с другого устройства.
5. Без собственного сохранённого имени Mac-клиент теперь называется
   «MacBook · PairDrop Fork». Пользовательское имя не меняется.
   На телефоне выбирайте этот приёмник, а не старый Chrome «M1».
6. Текст: выделить → правый клик → Службы → Отправить текст через PairDrop.
   Файлы: Finder → Службы → Отправить через PairDrop или Поделиться → PairDrop.
   При первой отправке выберите сопряжённый Android. Выбор запомнится.
   Клиент ждёт сохранённый телефон до 15 секунд; появление Chrome раньше
   телефона не перенаправляет отправку в Chrome. Повторно выбирать файл не надо.
   Если сохранённое устройство недоступно или сопряжение изменилось, появится
   новый выбор получателя. Отправка начнётся только после вашего подтверждения.
   «Меню → Отправить файлы…» использует ту же исправленную очередь.

Приём с Android
7. Разрешите уведомления PairDrop Fork в macOS. Нативный запрос содержит
   «Принять» и «Отклонить». Нажатие самого уведомления открывает диалог приёма
   этого файла. Если окно активно, диалог появляется сразу.
   Без уведомлений ожидающие запросы доступны через «Меню → Входящие запросы».
8. Уведомление с логотипом Chrome и надписью pairdrop.net относится к старой
   вкладке браузера, а не к этому приложению. Старые уведомления можно закрыть.
9. Полученные файлы находятся в Загрузки/PairDrop; нажатие уведомления о сохранении
   показывает файл в Finder. Ссылка открывается в браузере по нажатию,
   обычный текст копируется в системный буфер. Выполненные передачи не повторяются.

Если системное меню скрыто
10. Служба включается в настройках клавиатуры → Сочетания → Службы.
    Share extension включается в настройках расширений «Общий доступ».
    Регистрация локально подписанного расширения требует проверки на вашем Mac;
    Службы предоставляют отдельный путь отправки.

Подпись и пределы проверки
Сборка имеет локальную подпись без нотариального заверения Apple. Если Gatekeeper
блокирует запуск, используйте «Конфиденциальность и безопасность → Всё равно открыть».
Ни Homebrew, ни Xcode, ни Terminal для обычной установки не требуются.
Mac должен бодрствовать, приложение — работать. Выход через «Меню → Выйти»
или Cmd+Q завершает приём. Нулевого потребления памяти у фонового процесса нет.
Для нового фонового приёма установите APK PairDrop Fork из общего архива.
Старая Android-программа не обновляется Mac-приложением. Фактический расход
батареи и надёжность длительного сна на A57 требуют проверки на телефоне.
Интернет-режим зависит от WebRTC, NAT и pairdrop.net.
Нет установленного приложением ограничения размера. Нужны свободный диск и связь;
старый Android-клиент может расходовать память на Blob. Mac пишет файлы частями.
Универсальную вставку картинок или файлов в поля любых приложений эта версия не даёт.
